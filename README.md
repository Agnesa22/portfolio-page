# Agnesa Portfolio

Persönliche Portfolio-Website im Rahmen des Moduls Web Engineering an der BFH.

## Live Website

https://agnesa22.github.io/portfolio-page/

## Über das Projekt

Die Portfolio-Seite dient als persönliche digitale Visitenkarte und zeigt ausgewählte Projekte, Kompetenzen und technische Erfahrungen aus dem Bereich Wirtschaftsinformatik.

Der Fokus liegt auf einer modernen, responsiven und benutzerfreundlichen Darstellung mit interaktiven und dynamischen Funktionen.

## Inhalte

Die Website enthält:

- persönliche Kurzvorstellung
- Skills und Kompetenzen
- ausgewählte Projekte
- interaktive Projekt-Detailansichten
- dynamisch geladene GitHub-Repositories
- Kontaktformular mit Validierung
- responsive Navigation für Desktop, Tablet und Mobile

## Projekte

### CasaSierra

Konzeption und Entwicklung einer modernen Website für ein Immobilien- und Treuhandunternehmen.

**Technologien:**  
HTML, CSS, JavaScript

### FairFlat

Entwicklung eines UX/UI-Konzepts für eine App zur Organisation des Zusammenlebens in Wohngemeinschaften.

**Tools und Methoden:**  
Figma, UX Research, Prototyping

## Technische Funktionen

Die Portfolio-Seite beinhaltet unter anderem:

- dynamische Projektdarstellung mit JavaScript
- DOM-Manipulation
- GitHub REST API Integration
- lokale Zwischenspeicherung mit localStorage
- Fehlerbehandlung bei API-Anfragen
- clientseitige Formularvalidierung
- Live-Zeichenzähler im Kontaktformular
- dynamische Erstellung von E-Mail-Inhalten
- interaktive Projekt-Modals
- Keyboard- und Escape-Steuerung
- Fokusmanagement für Dialoge
- Scroll- und Reveal-Animationen
- responsive Layouts mit CSS Grid, Flexbox und Media Queries

## Technologien

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages
- GitHub REST API
- Figma

## Responsive Design

Die Website wurde für verschiedene Bildschirmgrössen optimiert:

- Desktop
- Tablet
- Smartphone

Dabei werden unter anderem CSS Grid, Flexbox, Media Queries und flexible Grössen verwendet.
